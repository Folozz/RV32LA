## Verilog 源码与物理约束说明

| 文件名称 | 层次定位 | 核心功能与微架构技术特性 |
|---|:---:|---|
| **`fpga_top.v`** | 综合顶层 | 板级顶层封装。内置 1024 周期 3 级同步 POR 上电复位发生器；统一连接 27MHz 时钟、复位、串口、4 键 4 灯与探针。 |
| **`rv32_soc.v`** | 系统总线 | SoC 片上总线互联与 MMIO 地址译码；实现硬件 Snoop 监听器，保障数据-指令 Cache 强一致性；调度片上逻辑分析仪与外设。 |
| **`rv32_core.v`** | 处理器核 | RV32I 经典 IF-EX-WB 三级流水线；WB→EX 全前递消除 RAW 依赖；32 项 BTB 动态分支预测实现 0 气泡推测取指；完整 40 条基础整数指令及特权 CSR/精确异常支持。 |
| **`btb_trap_unit.v`** | 控制单元 | 包含 32 项 BTB 动态分支预测器（2-bit 饱和状态机）与机器模式异常/中断特权控制单元（含 CSR、中断仲裁与向量表）。 |
| **`cache_2way.v`** | 缓存系统 | 2 路组相联双 Cache（1 KB I-Cache + 1 KB D-Cache）；4 字总线突发重填；直写（Write-Through）策略与数据 RAM 解耦推断。 |
| **`soc_ram.v`** | 片上主存 | 64 KiB 片上统一双端口同步 RAM；带 4-bit 字节选通写掩码；内联完整固件。 |
| **`logic_analyzer.v`** | 专用外设 | 8 通道片上逻辑分析仪 IP；1~65535 级宽时钟分频；立即/边沿触发；片上 1024 样本专用双口 RAM 硬件高速缓冲。 |
| **`uart.v`** | 通信外设 | 115200 8N1 全双工工业级串口收发控制器；带黏滞错误标志与原子清除逻辑。 |
| **`key_latch.v`** | 人机交互 | 4 通道 5ms 硬件消抖按键锁存器；下降沿翻转状态量，支持实体按键随时自主控制板载 LED 亮灭。 |
| **`top.fdc`** | 物理约束 | 约束文件；绑定 27MHz 时钟周期与芯片物理引脚。 |
