# RV32LA 片上固件源码工程说明

## 一、 文件结构与职责清单

| 相对路径 | 模块类型 | 核心职责与关键技术实现 |
| :--- | :---: | :--- |
| **`start.S`** | 引导汇编 | **CPU 复位第一现场**。设置全局指针 `gp`、建立栈指针 `sp`（向低地址生长，预留 8 KiB 调用栈）、清零 `.bss` 数据段、初始化陷入向量寄存器 `mtvec` 指向 `trap_entry`，随后跳转执行 `call main`。 |
| **`link.ld`** | 链接脚本 | **64 KiB 统一内存拓扑规约**。定义 `ORIGIN = 0x00000000, LENGTH = 64K` 物理空间，规范 `.text`、`.data`、`.bss` 段排布，并添加栈深度防溢出静态断言（`ASSERT(__image_end < __stack_top - 8192)`）。 |
| **`platform.h`** | 硬件定义 | **外设 MMIO 物理基地址与宏封装**。定义串口（`0x20000000`）、GPIO（`0x20001000`）、定时器（`0x20002000`）、逻辑分析仪控制（`0x20003000`）及采样缓冲（`0x30000000`）物理映射窗口与底层驱动声明。 |
| **`platform.c`** | 驱动实现 | **基础外设驱动函数库**。实现 `putchar_uart`、`puts_uart`、`print_hex`、`print_dec` 底层字符格式化；内置 128 字节软件 RX FIFO 与全双工高频轮询，消除串口忙等导致的溢出丢包；实现 `timer_cycles` **64 位无撕裂高-低-高原子防回绕时钟读取算法**；提供非阻塞串口读取 `getchar_uart`。 |
| **`command.h`** | 交互规约 | **流式命令状态机定义**。定义单行接收缓存结构体 `command_line`、CRLF 换行过滤、溢出丢弃错误码与解析后采集参数结构体 `capture_command`。 |
| **`command.c`** | 解析引擎 | **健壮流式命令解析引擎**。负责从串口流式字符中提取分频、深度、触发模式参数（如 `c 1 32 0 1`）。内部采用**等价无除法常数边界检查**，避免 RV32I 纯整数指令集因频繁调用软件除法造成运行超时。 |
| **`demo.c`** | 应用主程 | **逻辑分析仪与综合应用入口**。包含 `main()` 入口函数及 `capture()` 采样驱动。向硬件采样 IP 下发配置并启动采样，配置基于分频比与触发模式的动态安全超时保护，采样完成后从双口 RAM 读出波形、计算校验和并通过串口格式化回传。支持 `h` (帮助)、`i` (指令集自测)、`t` (中断自测)、`b` (CoreMark)、`g` (GPIO)、`c` (采样) 完整交互命令集。 |
| **`coremark_port/core_portme.h`** | 官方桩头文件 | **EEMBC CoreMark 平台移植配置**。指定当前硬件平台为 32 位、主频 27 MHz、定义计时变量类型 `CORETIMETYPE`、数据对齐规范与编译器优化标记。 |
| **`coremark_port/core_portme.c`** | 官方桩实现 | **CoreMark 硬件计时器接口**。实现 `start_time()` 与 `stop_time()`，调用底层 64 位 `timer_cycles()` 记录精确时钟周期，输出 `RAW_TICKS_HEX` 纳秒级跑分依据。 |
| **`coremark_port/ee_printf.c`** | 格式化引擎 | **超轻量嵌入式 `printf` 实现**。剥离臃肿的标准 C 库（glibc/newlib），以仅十几 KB 的紧凑代码实现全功能格式化输出，直接对接硬件 `putchar_uart()` 串口驱动。 |

## 二、 内存与外设 MMIO 地址分配表

系统采用统一编址架构，CPU 访问外设与访问片上 RAM 均通过标准 Load/Store 指令（`LW` / `SW`）完成：

| 物理地址范围 | 映射外设 / 设备 | 访问位宽 | 读写权限 | 描述 |
| :--- | :--- | :---: | :---: | :--- |
| `0x00000000 ~ 0x0000FFFF` | **片上统一 RAM** | 8/16/32 位 | 读 / 写 | 64 KiB 代码与数据主存储器（内联固件） |
| `0x20000000 ~ 0x2000000C` | **UART 串口控制器** | 32 位 | 读 / 写 | 波特率 115200 8N1，含发送状态、接收数据与错误清除寄存器 |
| `0x20001000 ~ 0x20001004` | **GPIO / LED 控制器** | 32 位 | 读 / 写 | 低 4 位输出控制板载 LED，支持实体按键消抖自主翻转 |
| `0x20002000 ~ 0x2000201C` | **64位高精度定时器** | 32 位 | 只读 | 64位无撕裂 cycle 计数器与 27.000 MHz 预设主频信息 |
| `0x20003000 ~ 0x20003018` | **逻辑分析仪控制寄存器** | 32 位 | 读 / 写 | 启动/复位使能、状态监控、16位时钟分频、采样深度、触发通道配置 |
| `0x30000000 ~ 0x30000FFF` | **逻辑分析仪双口采样缓冲** | 32 位 | 只读 | 专用硬件高速双口 RAM 窗口，存放 1024 点 8 通道数字信号样本 |

## 三、 软硬件启动与执行工作流

```
[硬件复位释放]
       │
       ▼
[0x00000000: start.S] ───► 1. 建立全局指针 gp 与 8KiB 调用栈指针 sp
                           2. 清零 .bss 数据段
                           3. 绑定 mtvec = trap_entry
                           4. 执行 call main
       │
       ▼
[demo.c: main()] ────────► 1. 串口打印系统 Banner: "PANGO RV32I BENCHMARK AND DEMO"
                           2. 向 GPIO (0x20001000) 写入 0x5A 完成回环自检并驱动板载 LED
                           3. 打印指令菜单与就绪提示: "Commands: h; i; t; b; g; c 1 32 0 1\nREADY RV32LA"
                           4. 正式进入流式命令监听主循环
       │
       ▼
[交互命令集支持] ────────► • 'b' : 触发运行官方 CoreMark 跑分，验证 CPU 算力与 CRC
                           • 'g' : 实时读取 GPIO IN (按键) 与 GPIO OUT 寄存器状态
                           • 'h' : 打印支持的命令帮助列表
                           • 'c' : 解析分频/深度/触发参数并启动逻辑分析仪采样
```
